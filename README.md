# IP카메라 기술 노트

IP카메라 개발에 쓰이는 기술을 하나씩 정리한다. 채용 공고에 나열된 요구 기술을 출발점으로
삼되, 항목마다 **직접 확인하는 방법**을 붙인다. 읽고 끝나면 남지 않는다.

## 이 노트의 규칙

- **한 항목 한 페이지.** 목차만 늘리지 않는다. 빈 페이지는 만들지 않는다.
- **왜 필요한지를 먼저 쓴다.** IP카메라에서 그 기술이 어디에 쓰이는지 모르면 외워도 사라진다.
- **직접 해보는 절차를 넣는다.** 명령 한 줄이라도 손으로 확인할 수 있게.
- **겪은 것은 겪은 대로 쓴다.** 남의 설명을 옮긴 부분과 직접 확인한 부분을 구분한다.

## 채용 공고와의 대응

이 노트의 항목들이 실제 직무에 어떻게 묶이는지.

| 직무 | 필요한 단계 |
|---|---|
| Embedded Linux BSP | 0 · 1 · 6 |
| Network Camera App SW | 0 · 1 · 4 · 5 (+2·3 얕게) |
| Image Quality SW | 0 · 2 · 3 (+신호처리) |
| VMS SW | 0 · 4 · 7 |
| 카메라 회로설계 | 8 (+2 얕게) |

**0단계와 1단계는 어느 직무로 가도 필요하다.** 거기서 아끼면 나머지가 전부 겉돈다.

## 페이지 쓰는 형식

[템플릿](docs/_템플릿.md) 참고. 항목마다 여섯 부분이다.

```
한 줄 정의  →  왜 필요한가  →  최소 이해 수준  →  직접 해보기
            →  더 들어가면  →  참고
```

「직접 해보기」가 없으면 그 페이지는 아직 미완성이다.
