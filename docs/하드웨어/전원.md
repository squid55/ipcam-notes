# 전원 · 레귤레이터

> 들어온 전기를 각 부품이 필요한 전압으로 바꿔 나눠 주는 회로.
> 여기가 불안하면 증상이 소프트웨어 버그처럼 보인다.

## 왜 필요한가

「간헐적으로 재부팅된다」 · 「무거운 작업을 하면 멈춘다」 ·
「카메라를 붙이면 보드가 죽는다」 — 이런 증상의 상당수가 전원이다.

그리고 IP카메라는 **PoE 로 전원을 받는 경우가 많아** 전력 예산이 정해져 있다.
적외선 조명과 PTZ 모터를 함께 켜면 예산을 넘기기 쉽다.

## 최소 이해 수준

- **전압 · 전류 · 전력.** `P = V × I`. 부품이 요구하는 것은 전압이고,
  실제 부담이 되는 것은 전류다. **레귤레이터의 한계는 전류로 표시된다.**
- **레귤레이터 두 종류.**

  | | LDO (선형) | 스위칭 (벅 / 부스트) |
  |---|---|---|
  | 방식 | 남는 전압을 열로 버린다 | 스위칭으로 변환 |
  | 효율 | 낮다 (전압 차가 크면 심하다) | 높다 (85~95%) |
  | 노이즈 | 매우 적다 | 스위칭 잡음이 있다 |
  | 부품 수 | 적다 | 인덕터 등 필요 |
  | 쓰는 곳 | 아날로그 · 센서 전원 | 코어 · 주 전원 |

  **LDO 의 손실 = (입력전압 − 출력전압) × 전류.**
  5V → 1.8V 를 500mA 로 쓰면 1.6W 가 열이 된다. 발열 문제가 여기서 생긴다.
- **벅(step-down)과 부스트(step-up).** 내리는 것이 벅, 올리는 것이 부스트.
  올리려면 에너지를 모아야 하므로 입력 전류가 출력 전류보다 크다.
- **차지 펌프.** 인덕터 없이 커패시터로 전압을 올리거나 반전한다.
  전류가 작은 용도(OTP 퓨징 전압 · LCD 바이어스)에 쓴다.
  **전류를 많이 못 내는 것**이 특징이다.
- **전원 시퀀스가 중요하다.** 여러 전압을 쓰는 칩은 **켜는 순서와 시간**이
  데이터시트에 정해져 있다. 순서를 어기면 래치업이 일어나거나 초기화가 실패한다.
  → [디바이스 트리](../BSP/디바이스트리.md) 의 regulator 참조
- **인러시(inrush) 전류.** 전원을 켜는 순간 커패시터를 채우느라 큰 전류가 흐른다.
  정상 전류 기준으로 어댑터를 고르면 **켤 때만 실패**한다.
- **PoE 등급.** IEEE 802.3af/at/bt.

  | 규격 | 급전측 | 수전측 사용 가능 |
  |---|---|---|
  | 802.3af (PoE) | 15.4W | 약 12.95W |
  | 802.3at (PoE+) | 30W | 약 25.5W |
  | 802.3bt | 60~90W | 51~71W |

  **케이블 손실 때문에 수전측 예산이 더 작다.** 100m 를 가정한 값이다.
- **리셋과 브라운아웃.** 전압이 기준 아래로 내려가면 감시 회로가 리셋을 건다.
  이 리셋은 로그에 남지 않는 경우가 많아 **원인 모를 재부팅**으로 보인다.

## 직접 해보기

### 1. 전원 레일 목록 만들기

회로도에서 전압별 네트를 찾아 표로 정리한다.

```
레일     전압    공급원      주요 소비처        한계 전류
VIN      12V     어댑터      전체
3V3      3.3V    U5 (벅)     SoC I/O, 플래시    2A
1V8      1.8V    U6 (LDO)    센서 I/O           300mA
VDD_CORE 0.9V    U7 (벅)     SoC 코어           3A
```

**이 표를 만들어 두면** 이후의 모든 전원 문제를 여기서부터 볼 수 있다.
→ [회로도 읽기](회로도읽기.md)

### 2. 각 레일 전압 측정

멀티미터 DC 전압 모드로 테스트 포인트에서 잰다.

```
① 무부하 (부팅 직후 대기)
② 부하 (스트리밍 중 · IR 조명 켜짐 · 모터 동작)
```

**②에서 값이 떨어지면 그 레일이 전류 부족**이다.
보통 ±5% 안에 들어야 한다. 3.3V 가 3.1V 로 내려가면 문제다.

### 3. 소비 전력 재기

인라인 전류계나 USB 전력계를 넣어 잰다.

```
상태별로 재둔다:
  대기            ___ mA
  스트리밍 1채널   ___ mA
  스트리밍 + IR    ___ mA
  + PTZ 동작       ___ mA   ← 최대값
```

**최대값에 여유 30% 를 더한 것**이 어댑터·PoE 등급의 기준이다.

### 4. 순간 강하(드롭)를 잡기

멀티미터는 평균만 보여준다. 짧은 강하는 오실로스코프로만 보인다.

```
① 전원 레일에 프로브를 물린다 (AC 커플링, 작은 전압/칸)
② 트리거를 하강 에지로, 임계값을 정상값의 90% 에 둔다
③ 문제가 나는 동작을 실행한다
```

리셋과 동시에 강하가 잡히면 원인이 확정된다. → [오실로스코프](계측.md)

### 5. 발열 확인

```bash
# SoC 내부 온도 센서가 있으면
cat /sys/class/thermal/thermal_zone*/temp
```

레귤레이터 자체의 온도는 손이나 열화상으로 본다.
**손으로 오래 못 댈 정도면 LDO 손실이 큰 것**이고,
전압 차를 줄이거나 스위칭으로 바꿔야 한다.

### 6. PoE 급전 상태 확인

스위치 쪽에서 확인하는 것이 가장 확실하다.

```bash
# 관리형 스위치에서 포트별 급전 전력 조회 (예)
snmpwalk -v2c -c public <스위치> 1.3.6.1.2.1.105.1.1.1.4
```

**할당 전력이 요청보다 작으면** 카메라가 기능을 제한하거나 재부팅을 반복한다.

### 7. 전원 문제인지 가르는 빠른 시험

```
① 외부 어댑터(충분한 용량)로 바꿔 본다 → 증상이 사라지면 전원
② 부하를 하나씩 끈다 (IR 끄기 · 해상도 낮추기 · 모터 정지)
   → 특정 부하에서만 생기면 그 부하의 전류
③ 다른 보드로 바꿔 본다 → 그 보드만의 문제인지
```

**소프트웨어를 고치기 전에 이 세 가지를 해 보는 것**이 시간을 아낀다.

## 더 들어가면

- **디커플링과 벌크 커패시터.** 순간적인 전류 요구를 커패시터가 받아 준다.
  용량이 부족하면 스위칭이 따라가기 전에 전압이 꺼진다.
- **접지 설계.** 아날로그 접지와 디지털 접지를 분리하고 한 점에서 잇는다.
  섞으면 스위칭 잡음이 센서 신호에 들어가 **영상에 줄무늬**가 생긴다.
- **효율과 발열의 관계.** 90% 효율로 10W 를 쓰면 1W 가 열이다.
  밀폐된 카메라 하우징에서는 그 1W 가 온도를 크게 올린다.
- **저전력 모드.** 사용하지 않는 레일을 내린다.
  리눅스에서는 regulator 프레임워크와 runtime PM 이 담당한다.
  → [디바이스 드라이버](../BSP/디바이스드라이버.md)
- **서지와 낙뢰.** 실외 카메라는 전원·이더넷 양쪽에 서지 보호가 필요하다.
  제품 규격에 서지 시험이 포함된다.
- **전원 시퀀서 IC.** 레일이 많으면 순서를 전용 칩이 맡는다.
  그 칩이 「어느 레일이 올라오지 않았다」는 정보를 갖고 있어 진단에 쓸 수 있다.

## 흔한 오해

### 「어댑터 전압만 맞으면 된다」

전류 용량이 더 중요하다. 12V 1A 어댑터에 12V 1.5A 가 필요한 보드를 붙이면
**부하가 걸릴 때만 전압이 내려가** 간헐적으로 리셋된다.
정격이 맞아도 인러시를 못 받치는 저가 어댑터가 있다.

### 「간헐적 재부팅은 커널 문제다」

커널 패닉이면 콘솔에 흔적이 남는다. **아무 로그도 없이 다시 부팅되면
전원이나 워치독**이다. UART 콘솔을 붙여 두고 마지막 출력이
무엇인지 보는 것이 첫 단계다. → [UART · I2C · SPI · GPIO](../BSP/버스.md)

### 「USB 케이블로 급전하면 편하다」

케이블 저항 때문에 전압이 떨어진다. 가늘고 긴 케이블에서 특히 심해서
**보드 쪽에서 재면 4.6V** 인 경우가 흔하다. 케이블을 바꾸면 증상이 사라진다.

### 「LDO 가 노이즈가 적으니 다 LDO 로 하면 된다」

전압 차 × 전류만큼 열이 난다. 12V → 3.3V 를 1A 로 LDO 로 하면
**8.7W 가 열**이다. 실제로는 불가능하다. 스위칭으로 내리고
민감한 부분만 LDO 로 한 번 더 거르는 구성이 표준이다.

### 「PoE 는 규격이 있으니 어느 스위치든 된다」

비표준 급전(패시브 PoE)을 쓰는 장비가 있고, 그것에 표준 장치를 붙이면
협상 없이 전압이 인가돼 손상될 수 있다. **급전 방식을 확인**해야 한다.

### 「전력은 최대값만 보면 된다」

평균도 봐야 한다. PoE 예산은 평균 소비로 배분되고,
스위치 전체의 급전 용량에 여러 카메라가 함께 들어간다.
**카메라 8대를 한 스위치에 달 때** 그 합이 스위치 용량을 넘기지 않아야 한다.
